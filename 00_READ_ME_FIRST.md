## 🚀 GET STARTED IN 5 MINUTES

### Step 1: Edit Database URL

```
Edit .env.local:
DATABASE_URL="mysql://root:YOUR_PASSWORD@localhost:3306/hms"
```

### Step 2: Run Setup

```bash
node complete-setup.js
```

### Step 3: Install

```bash
npm install
```

### Step 4: Initialize Database

```bash
npx prisma generate
npx prisma db push
npm run db:seed
```

### Step 5: Start

```bash
npm run dev
```

### Step 6: Visit

```
http://localhost:3000
```
